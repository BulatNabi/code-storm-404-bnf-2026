Ты анализируешь структуру технического задания для разбиения на логические чанки.

ЦЕЛЬ:
Исправить иерархию заголовков (уровни вложенности, нумерацию) и вернуть структурированный JSON.

ВХОДНЫЕ ДАННЫЕ:
JSON массив заголовков с полями:
- line_idx: позиция в исходном файле (НЕ ИЗМЕНЯТЬ!)
- level: текущий уровень (может быть неправильным)
- title: текст заголовка
- source: источник ("explicit" или "llm")

ЗАДАЧИ:
1. Исправить level по правилам ниже
2. Исправить title если нужно (убрать лишние символы, исправить нумерацию)
3. Удалить дубликаты и невалидные заголовки
4. Вернуть JSON с исправленными данными

КРИТИЧЕСКИ ВАЖНО:
- line_idx НЕЛЬЗЯ ИЗМЕНЯТЬ! Это позиция в файле.
- Порядок заголовков НЕЛЬЗЯ МЕНЯТЬ! (сортировка по line_idx)
- Удалённые заголовки просто не включай в ответ

═══════════════════════════════════════════════════════════════

ПРАВИЛА ОПРЕДЕЛЕНИЯ LEVEL:

level = количество ЧИСЕЛ в номере раздела

Примеры:
- "1 Общие сведения" → 1 число → level=1
- "1.1 Полное наименование" → 2 числа → level=2
- "1.1.1 Подпункт" → 3 числа → level=3
- "4.2.3.1 Детали" → 4 числа → level=4

Для заголовков БЕЗ номера (ТЕРМИНЫ, ОГЛАВЛЕНИЕ):
- level=1 (верхний уровень)

═══════════════════════════════════════════════════════════════

ПРАВИЛА ИСПРАВЛЕНИЯ НУМЕРАЦИИ:

1. ДУБЛИ НОМЕРОВ: Если два заголовка имеют одинаковый номер:
   - Первый оставляем
   - Второй получает следующий номер (2.1 → 2.2)

2. УБЫВАНИЕ НОМЕРОВ: Если после 3.1 идёт 2.2 → исправить на 3.2

3. ДУБЛИ ВЕРХНЕГО УРОВНЯ: "3 Характеристики" + "3 Требования" → второй становится "4 Требования"

4. ЗАГОЛОВКИ БЕЗ НОМЕРА внутри секции: дать следующий номер
   - После "4.3.1 Техническое" идёт "Методическое" → "4.3.2 Методическое"

═══════════════════════════════════════════════════════════════

ПРАВИЛА ФИЛЬТРАЦИИ:

НЕ ВКЛЮЧАЙ в ответ:
- Заголовки глубже 4 уровня (5+ чисел в номере)
- Поля форм (String, YYYY-MM-DD, Заполняемое поле)
- Вводные фразы без номера ("Модуль включает:", "Система обеспечивает:")
- Дубликаты из оглавления (если есть два одинаковых заголовка - оставь с большим line_idx)
