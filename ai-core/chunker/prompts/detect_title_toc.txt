Ты анализируешь начало технического задания.

ЦЕЛЬ:
Определить границы титульной страницы и оглавления (содержания).

ВХОДНЫЕ ДАННЫЕ:
Фрагмент документа с номерами строк (line_idx).

ОПРЕДЕЛЕНИЯ:
1. ТИТУЛЬНАЯ СТРАНИЦА - первые строки с названием документа, организацией, годом, версией и т.д.
   Обычно 1-5 строк в начале документа.

2. ОГЛАВЛЕНИЕ (СОДЕРЖАНИЕ) - раздел с заголовком "Содержание" или "Оглавление" + таблица/список разделов документа.
   Может быть в виде:
   - Markdown таблицы (| ... |)
   - Списка ссылок ([1 Название](.))
   - Ссылок с якорями ([**ТЕРМИНЫ 4**](#_heading=h.30j0zll))
   - Ссылок с номерами страниц ([6.1. Общие положения 81](.))
   - Простого списка разделов

   ВАЖНО:
   - Паттерн [**ТЕКСТ НОМЕР**](#...) встречается ТОЛЬКО в оглавлениях, никогда в контенте!
   - Паттерн [номер_раздела Название номер_страницы](.) - это ВСЕГДА оглавление:
     Примеры: [6.1. Общие положения 81](.), [4.2. Условия проведения испытаний 82](.)

   Оглавление заканчивается перед первым нумерованным разделом "1 Общие сведения" или структурным заголовком (ТЕРМИНЫ, ВВЕДЕНИЕ).

ЗАДАЧА:
1. Найди строки титульной страницы
2. Найди строки оглавления (от заголовка "Содержание" до первого раздела)
3. Верни JSON с диапазонами [start, end) где end НЕ включается

ФОРМАТ ОТВЕТА:
Строго JSON без markdown обёртки, без комментариев:

{
  "title_page_range": [0, 4],
  "toc_range": [4, 34]
}

Если титульной страницы нет - верни "title_page_range": null
Если оглавления нет - верни "toc_range": null

ВАЖНО:
- title_page_range и toc_range НЕ должны пересекаться
- end - это индекс первой строки ПОСЛЕ зоны (не включается)
- Если оглавления нет в начале документа - верни null

НАЧИНАЙ ОТВЕТ СРАЗУ С { БЕЗ ПРЕАМБУЛЫ.
