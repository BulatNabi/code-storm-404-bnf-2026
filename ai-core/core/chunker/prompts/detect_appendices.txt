ВХОДНЫЕ ДАННЫЕ:
Фрагмент от последнего основного раздела до конца документа с номерами строк.

ЗАДАЧА:
Найди строку, с которой начинаются ПРИЛОЖЕНИЯ (если они есть).

ПРИЗНАКИ ПРИЛОЖЕНИЯ:
- Заголовки: "ПРИЛОЖЕНИЕ", "Приложение А"
- Идут ПОСЛЕ завершения последнего нумерованного раздела
- Содержат формы, таблицы, дополнительные материалы
- НЕ являются подразделами основного раздела (5.1, 5.2 и т.д.)

ФОРМАТ ОТВЕТА:
Строго JSON без markdown обёртки, без комментариев:

{
  "appendix_start_line": 450
}

Если приложений нет:
{
  "appendix_start_line": null
}

ВАЖНО:
- appendix_start_line = номер первой строки первого приложения
- Всё от этой строки до конца документа считается приложениями
- Если приложений нет - верни null
