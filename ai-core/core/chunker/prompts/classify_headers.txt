Ты анализируешь список подозрительных строк из технического задания, чтобы определить,
какие из них являются ЗАГОЛОВКАМИ разделов документа.

═══════════════════════════════════════════════════════════════

ОПРЕДЕЛЕНИЕ ЗАГОЛОВКА:

Заголовок — это нумерованный раздел, который структурирует документ.

ОБЯЗАТЕЛЬНЫЕ ПРИЗНАКИ заголовка:
✓ Начинается с номера раздела (1, 1.2, 3.1.5, 4.2.1.3 и т.д.)
✓ Содержит содержательное название раздела (не просто "Описание" или "Требования")
✓ Может иметь markdown форматирование (##, **bold**) или быть обычным текстом

ФОРМАТ НОМЕРА:
- Правильно: "1.2 Название", "3.1.5 Требования"
- Правильно (с пробелами): "1.2      Название"
- Неправильно: "1. Пункт списка" — это элемент списка, не раздел
- Неправильно: "Раздел включает" — нет номера

═══════════════════════════════════════════════════════════════

НЕ ЯВЛЯЮТСЯ ЗАГОЛОВКАМИ:

✗ Поля форм: "Полное наименование: ...", "Адрес: ...", "Телефон: ..."
✗ Пункты списков: - элемент"
✗ Вводные фразы: "Модуль должен включать:", "Основные функции:", "Система обеспечивает:"
✗ Технические метки: "Рис 1.", "Таблица 2", "Приложение А"
✗ Описательные фразы: "В рамках работ выполняется:", "Должны быть предусмотрены:"
✗ Названия ролей: "Для администраторов", "Пользователи:", "Модераторы"
✗ Обрывки текста: "администратора", "оплаты", "требования"

═══════════════════════════════════════════════════════════════

ОПРЕДЕЛЕНИЕ УРОВНЯ:

Уровень = количество ЧИСЕЛ в номере раздела.

АЛГОРИТМ:
1. Извлеки номер раздела (игнорируя markdown ##, ** и пробелы)
2. Раздели по точке: "3.1.5" → ["3", "1", "5"]
3. Посчитай количество: 3
4. Уровень = 3

ПРИМЕРЫ:
- "1 Введение" → уровень 1
- "2.3 Назначение" → уровень 2
- "4.1.2 Требования к безопасности" → уровень 3
- "## 3.2.1.4 Подсистема" → уровень 4

ЕСЛИ НОМЕРА НЕТ → level = null, is_header = false

═══════════════════════════════════════════════════════════════

ИЗВЛЕЧЕНИЕ НАЗВАНИЯ (title):

ВАЖНО: Верни ТОЧНОЕ название из текста, БЕЗ изменений и дополнений!

АЛГОРИТМ:
1. Удали markdown форматирование (##, **, ~~)
2. Удали номер раздела и точку после него
3. Удали лишние пробелы
4. Верни оставшийся текст КАК ЕСТЬ

❌ НЕПРАВИЛЬНО (галлюцинация):
Входные данные: "Полное наименование: Портал «Маркетстория»."
Ответ LLM: "Полное наименование Портала и его условное обозначение"
→ Откуда взялось "и его условное обозначение"?!

✅ ПРАВИЛЬНО:
Входные данные: "Полное наименование: Портал «Маркетстория»."
Ответ: null (это поле формы, не заголовок)

❌ НЕПРАВИЛЬНО:
Входные данные: "3. Возможность формирования заказа."
Ответ LLM: "Раздел «Чат»"
→ Причём тут "Чат"?!

✅ ПРАВИЛЬНО:
Входные данные: "3. Возможность формирования заказа."
Ответ: null (это пункт списка с номером "3.", а не раздел "3")

КРИТЕРИИ ОТБОРА:

Строка является заголовком ТОЛЬКО если:
1. ✓ Есть номер в формате X.Y.Z (не просто "1.", а "1" или "1.2")
2. ✓ После номера идёт содержательное название (не "Описание", а "Описание архитектуры")
3. ✓ Это не поле формы (нет ":" после первых 3 слов)
4. ✓ Это не вводная фраза (не начинается с "Модуль должен", "Система обеспечивает")
5. ✓ Это не пункт списка (номер не заканчивается точкой: "1.", "2.")

ПРИМЕРЫ:

ВХОДНЫЕ ДАННЫЕ: "Полное наименование: Портал «Маркетстория»."
АНАЛИЗ:
- Есть номер? НЕТ
- Есть ":"? ДА → это поле формы
ОТВЕТ: {"is_header": false, "level": null, "title": null}

ВХОДНЫЕ ДАННЫЕ: "3. Возможность формирования заказа."
АНАЛИЗ:
- Номер "3." — заканчивается точкой → это пункт списка, не раздел
ОТВЕТ: {"is_header": false, "level": null, "title": null}

ВХОДНЫЕ ДАННЫЕ: "## 3.2.1 Требования к архитектуре ИС"
АНАЛИЗ:
- Номер: "3.2.1" → 3 числа → уровень 3 ✓
- Название: "Требования к архитектуре ИС" ✓
ОТВЕТ: {"is_header": true, "level": 3, "title": "Требования к архитектуре ИС"}

ВХОДНЫЕ ДАННЫЕ: "Модуль должен поддерживать следующие способы оплаты:"
АНАЛИЗ:
- Есть номер? НЕТ
- Вводная фраза? ДА ("Модуль должен...")
ОТВЕТ: {"is_header": false, "level": null, "title": null}

ВХОДНЫЕ ДАННЫЕ: "администратора"
АНАЛИЗ:
- Обрывок текста без контекста
ОТВЕТ: {"is_header": false, "level": null, "title": null}

ФОРМАТ ОТВЕТА:

Строго JSON, один объект на строку:

{
  "results": [
    {"line_idx": int, "is_header": bool, "level": int|null, "title": string|null},
    ...
  ]
}

ПРАВИЛА:
- Если is_header = false → level = null, title = null
- Если is_header = true → level = количество чисел в номере, title = точное название
- НЕ ДОБАВЛЯЙ информацию, которой нет в тексте!
- НЕ МЕНЯЙ формулировки из оригинала!
