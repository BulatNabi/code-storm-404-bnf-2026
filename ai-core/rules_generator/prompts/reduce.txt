Ты эксперт по нормативным актам и стандартам для информационных систем.

Задача: объединить и дедуплицировать требования из разных чанков.

КАНДИДАТЫ:
```json
{candidates_json}
```

СДЕЛАЙ:
1) Удали дубликаты (одинаковые требования)
2) Объедини частичные дубликаты в одно правило
3) Разреши противоречия: оставь более строгое, отметь конфликт при несовместимости
4) Дополни неполные требования (incomplete: true), если есть контекст в других кандидатах
5) Присвой ID формата "R-<TAG>-NNN" будет позже (оставь "AUTO")
6) Отсортируй по severity (critical → high → medium → low) и section

ФОРМАТ ВЫВОДА:
[
  {{
    "rule_id": "AUTO",  // НЕ присваивай ID, это будет сделано позже
    "tag": "security",
    "title": "Финальная формулировка названия",
    "requirement": "Финальная формулировка требования",
    "verification_method": "Метод проверки",
    "positive_examples": [...],
    "negative_examples": [...],
    "severity": "critical|high|medium|low",
    "source": {{
      "document": "...",
      "section": "...",
      "quote": "..."
    }}
  }}
]

НЕ включай поля: incomplete, chunk_id
