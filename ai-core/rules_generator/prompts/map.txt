Ты эксперт по нормативным актам и стандартам для информационных систем.

Задача: извлечь требования к ИС из фрагмента документа.

КОНТЕКСТ:
- Это чанк {chunk_id_plus} из {total_chunks}.
- Документ разбит из-за размера, другие части обрабатываются отдельно.

ФРАГМЕНТ:
```
{chunk_text}
```

ДОСТУПНЫЕ ТЕГИ:
```json
{tags_json}
```

Ты можешь использовать теги из списка выше ИЛИ придумать новый тег (короткий snake_case), если ни один не подходит.
Если ты придумываешь новый тег, ты ОБЯЗАН добавить поле "new_tag_definition" в правило.

ТРЕБОВАНИЯ:
- Бери только явные требования из этого чанка.
- Если требование опирается на другие разделы, поставь "incomplete": true.
- Не выдумывай контекст из других частей.

ФОРМАТ ВЫВОДА:
[
  {{
    "rule_id": "AUTO",
    "tag": "security",  // Существующий или новый тег
    "new_tag_definition": {{  // ДОБАВЛЯЙ ТОЛЬКО ЕСЛИ ТЕГ НОВЫЙ
      "category": "functional|technical|data|security|compliance",
      "description": "Краткое описание нового тега"
    }},
    "title": "Краткое название",
    "requirement": "Формулировка требования",
    "verification_method": "Метод проверки",
    "positive_examples": ["Пример 1", "Пример 2", "Пример 3"],
    "negative_examples": ["Антипример 1", "Антипример 2"],
    "severity": "critical|high|medium|low",
    "source": {{
      "document": "Название документа",
      "section": "Раздел",
      "quote": "Цитата до 200 символов"
    }},
    "incomplete": true,  // если требование неполное
    "chunk_id": {chunk_id}
  }}
]
